When more data
does not help

A closed-form account of shortcut learning and reweighting

[Author 1] · [Author 2] · [Author 3]

Hi everyone. Our project is about shortcut learning: why a model that looks great on its test set can fall apart when one cue in the data changes. The short version of our answer: collecting more data does not fix it, reweighting does, and in our setting we can compute exactly how much it helps before running anything.

A practical finding

Reweight the validation set too

If the regularization strength is chosen on an unweighted validation set, model selection quietly undoes the reweighting: for α > 1 it picks the strongest penalty every time.

One practical lesson we did not expect. When we picked the regularization strength using a normal, unweighted validation set, the results drifted away from theory. The validation set still looks like the training environment, so for alpha above one it always chose the strongest regularization, which partly undoes the reweighting. The largest gap to theory was 6 points. Using the same weights in the validation loss fixes it: the largest gap drops to about 1 point. So if you reweight training, reweight model selection too.

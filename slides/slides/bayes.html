First result. We wrote down the Bayes-optimal classifier for the training environment. It puts weight 2 on the stable feature and log p over 1 minus p on the shortcut, which is 2.94 when p is 0.95. So relying on the shortcut is not a bug in training: it is the optimal answer for that data. From this we get a closed-form accuracy in any test environment q. At p equals 0.95 it predicts 95.8 percent in distribution, but only 39.4 percent when the shortcut reverses. Using only the stable feature gives 84.1 percent everywhere. Important point: none of these numbers depends on the sample size n.

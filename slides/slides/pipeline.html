Briefly, how the code is organised. A data generator, the models and metrics feed an experiment runner that writes CSV files. A separate theory module computes the predictions, and the analysis script puts the two side by side for every figure. The MNIST experiment is its own script with a small CNN. Everything uses fixed seeds and reproduces in about six minutes on a laptop CPU. The code and all results are on GitHub.
